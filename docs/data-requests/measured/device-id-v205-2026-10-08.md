# CH32V205 の識別情報実測 (2026-10-08)

ユーザーがCH32V205を接続していると報告した WCH-LinkE
`1a86:8010:497E8F06CE2E` を測定。flash・optionの書き込みと消去は未実施。

| 項目 | 実測 |
|---|---|
| Probe / firmware | WCH-LinkE / 2.22 (v42, raw `0216`) |
| AttachChip family byte | `0xce` |
| AttachChip chip_id / ChipInfo echo | `0x20510510` / `0x20510510` |
| メモリ `0x1ffff704` | `10 05 51 20` (LE32 = `0x20510510`) |
| silicon revision / 比較用ID | 1 / `0x20510500` (`0xffffff0f` mask) |
| ChipInfo flash / UID | 256 KiB / `0fb8abcd77d2bc4d` |
| `0x1ffff7e0` FLACAP | `00 01` (LE16 = 256 KiB) |
| `0x1ffff7e8..0x1ffff7f3` | `cd ab b8 0f 4d bc d2 77 ff ff ff ff` |

ChipInfo UIDはプローブ形式の8 byte。RMのUID領域は12 byteであり、同一形式とは扱わない。
`protection_raw=ffffffff`から読み出し保護状態は推定しない。


## 型番と資料の照合

WCH公式 [CH32V205EVT.ZIP](https://www.wch.cn/downloads/CH32V205EVT_ZIP.html) の
`EVT/EXAM/SRC/Peripheral/src/ch32v205_dbgmcu.c`、`DBGMCU_GetCHIPID`のコメントは
次のIDを明記する。`inc/ch32v205.h`の`CHIPID_BASE`は`0x1FFFF704`。

| 型番 | EVTのID | Flash / SRAM | 実機ID確認 |
|---|---|---|---|
| CH32V205CCT6 | `0x205205x0` | 256 KiB / 32 KiB | 未実施 |
| CH32V205RCT6 | `0x205105x0` | 256 KiB / 32 KiB | 実施 |
| CH32V205VCT6 | `0x205005x0` | 256 KiB / 32 KiB | 未実施 |
| CH32V203CCT6 | `0x205405x0` | 256 KiB / 32 KiB | 未実施 |

容量とパッケージは [CH32V205DS0.PDF](https://www.wch.cn/downloads/CH32V205DS0_PDF.html)
英語V1.3、PDF p.3の比較表とch32-device-data `index/parts.csv`で一致。
RCT6はLQFP64。型番はID表から解決し、チップ刻印の目視確認はしていない。
CH32V203CCT6は旧V203のCH32V20xとは異なり、この資料のCH32V205 familyに属する。

電子署名アドレスは [CH32V205RM.PDF](https://www.wch-ic.com/downloads/CH32V205RM_PDF.html)
英語V1.2、PDF p.457と `index/esig.csv`で照合。
debug配線(PA13/PA14、1-or-2-wire)、flash geometry、option layoutは生成DBに収載済み。

## 登録状態

[依頼0007](../0007-ch32v205-device-id.ja.md)のローカルdraftと出典付き暫定overlayを追加。
RCT6は`verified=true`、資料のみの3行は`verified=false`。全行`provisional=true`。
資料の持ち主へは未送信。`0xce`のfamily名も実測に基づき登録した。
ID確認済みは書き込み検証済みを意味しない。V205のflash書き込み経路は実機未検証。
