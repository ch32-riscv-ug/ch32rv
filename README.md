# ch32rv

Flashing and debugging tool for WCH CH32 RISC-V microcontrollers (under development, pre-implementation).

Aims to consolidate the functionality currently spread across probe-rs, wlink, minichlink, WCH OpenOCD, WCH-LinkUtility, wchisp, and wlink-iap into a single CLI plus reusable Rust library crates.
